## 定案(三源交叉 + SDK 決定性證據)

**這版 SDK 裡沒有 `claude-opus-5`。Opus 最高就是 `claude-opus-4-8`。** 所以:

1. `.env` 的 `claude-opus-5` 被 adapter reject（不在 SDK 清單）→ 靜默 fallback
2. Fallback 落到 `~/.claude/settings.json` 的 `"model": "opus[1m]"` → 解析成 **Opus 4.8 (1M)**
3. harness 宣告 Opus 4.8 (1M) —— 全對上
