3. 他重新 clone → 改 origin 指自己的 → 加 upstream 指你的 → **把 upstream 的 push URL 廢掉**
4. `git push -u origin main`，然後 `npm run hooks:install`

第 3 步的 `no-push` 別讓他省略——那是唯一擋住他手滑推爆你 `main` 的東西。
