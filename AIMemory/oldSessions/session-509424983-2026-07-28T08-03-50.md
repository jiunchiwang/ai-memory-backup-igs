# UK Slot 遊戲流程模式

## 基本狀態機

## 通用流程
1. 玩家下注 (Bet)

## 常見 Feature 模式
| 模式 | 觸發 | 行為 | 範例 |
|------|------|------|------|

| Expanding Wild | Wild 落定 | Wild 擴展整列 | |

| Feature Buy-in | 玩家付費 | 直接進 Feature（跳過觸發） | |
