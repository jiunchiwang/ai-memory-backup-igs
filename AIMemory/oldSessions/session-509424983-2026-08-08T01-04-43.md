### 二、計算公式

```
應納稅額 = (綜合所得總額 - 免稅額 - 扣除額 - 特別扣除額) × 稅率 - 累進差額
```

即：
```
課稅所得淨額 = 總所得 - 免稅額 - 扣除額 - 特別扣除額
應納稅額 = 課稅所得淨額 × 適用稅率 - 累進差額
```

---

### 三、114 年度（2025 年報稅）稅率級距

| 課稅所得淨額 | 稅率 | 累進差額 |
|-------------|------|---------|
| 0 ～ 590,000 | **5%** | 0 |
| 590,001 ～ 1,330,000 | **12%** | 41,300 |
| 1,330,001 ～ 2,660,000 | **20%** | 147,700 |
| 2,660,001 ～ 4,980,000 | **30%** | 413,700 |
| 4,980,001 以上 | **40%** | 911,700 |

> 📌 **累進稅率**：不是所得 500 萬就全部課 40%，而是分段計算——前 59 萬課 5%、接下來的課 12%……以此類推。「累進差額」就是把分段合併成一個公式的簡化。

**算在今年（1 月份），不是去年。**

台灣綜合所得稅採「實際給付日」原則（現金收付基礎），不是「應計基礎」：

- **薪資所得的認列時點 = 實際領到錢的日期**
- 所以 1 月領到的 12 月薪水，歸入「1 月所在的那個年度」

### 實務例子

| 情境 | 所得歸屬年度 |
|-----|-------------|
| 2025/12 工作，2026/1/5 發薪 | **2026 年度**（115 年報稅） |
| 2025/12 工作，2025/12/31 發薪 | **2025 年度**（114 年報稅） |

### 為什麼這樣設計？

1. **扣繳憑單依實際給付開立**：公司在發薪當月扣繳並申報，憑單日期就是付款日
2. **容易查核**：銀行入帳紀錄 = 所得歸屬年度，不需要追溯「這筆是哪個月的工作」

### 要注意的情況

- **年終獎金**：如果公司 1 月發放去年的年終，算「今年」所得
- **離職結算**：最後一筆薪水發放日決定歸屬年度

所以如果你 1 月看到帳戶入帳，那筆就是今年的所得，會出現在今年度的扣繳憑單上。

### 🤖 Assistant (上午7:01:44)

### 薪資單三個金額的差異

| 項目 | 意義 | 包含什麼 |
|-----|------|---------|
| **應發金額** | 公司「應該發給你」的總額 | 本薪＋津貼＋加班費＋獎金＋各種補貼 |
| **實領金額** | 你「實際入帳」的錢 | 應發金額 − 各項扣款 |
| **應稅薪資** | 要「課稅」的部分 | 應發金額中需計入綜所稅的項目 |

---

### 關係圖

```
應發金額
  │
  ├─ 扣款 ─→ 勞保費、健保費、勞退自提、所得稅預扣、其他
  │
  └─ 實領金額（= 應發 − 扣款）

應發金額
  │
  ├─ 免稅項目 ─→ 加班費（每月 46 小時內）、差旅費、伙食津貼（≤3,000/月）
  │
  └─ 應稅薪資（= 應發 − 免稅項目）
```

---

### 常見免稅（不計入應稅薪資）的項目

| 項目 | 免稅條件 |
|-----|---------|
| **加班費** | 每月 46 小時內免稅（超過部分要課稅） |
| **伙食津貼** | ≤ 3,000 元/月 |
| **差旅費** | 實報實銷性質 |
| **制服費、工具費** | 因工作必須的實支 |

---

### 實際例子

假設你的薪資單：

| 項目 | 金額 |
|-----|------|
| 本薪 | 50,000 |
| 加班費（30hr） | 5,000 |
| 伙食津貼 | 2,400 |
| **應發金額** | **57,400** |
| − 勞保費 | −1,100 |
| − 健保費 | −800 |
| − 所得稅預扣 | −2,000 |
| **實領金額** | **53,500** |

應稅薪資計算：
- 加班費 30hr 在 46hr 內 → 免稅
- 伙食津貼 2,400 ≤ 3,000 → 免稅
- **應稅薪資 = 50,000**（只有本薪）

---

### 重點

1. **應發 ≠ 應稅**：應發是公司給你的總額，應稅是其中要報稅的部分
2. **實領 ≠ 應稅**：實領是扣完各項費用後入帳的錢，跟稅基無關
3. **扣繳憑單上的數字 = 應稅薪資的年度加總**（不是應發也不是實領）

所以報稅時看的是「應稅薪資」，不是你每月實際領到的錢。
