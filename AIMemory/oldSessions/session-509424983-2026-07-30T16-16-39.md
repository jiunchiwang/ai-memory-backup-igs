## 三個節點的分工

`assets/game/Prefab/PerfGroup.prefab` 就是整套 RT 容器：

```
PerfGroup          ← m_RTRoot（平時 active=false）
├─ Node            ← sprite（cc.Sprite，用來顯示 RT）
└─ Camera_RT       ← camera（第二台相機，targetTexture 指向 RT）
```

`PerfGroup` 掛在 `Node_Reel.prefab` 裡；`RTCtrl` 這個 component 掛在 `Manager.prefab` 的 `Manager` 節點上，四個欄位（`sprite` / `camera` / `m_RTRoot` / `m_hideNodes`）是在 `MainGame.prefab` 用 **targetOverrides** 跨 prefab instance 接起來的（`MainGame.prefab:2889/2892/3018/3021/3024`）——這是為什麼直接搜 prefab 看到的值是 `null`，得看 `cc.TargetOverrideInfo` 才找得到。

## 關鍵三個 API

**`Init()`（RTCtrl.ts:113）** — 建 RT 並對齊主相機：
- `new RenderTexture()` + `reset({ width/height: view.getVisibleSize() })`
- 從 `director.getScene().getComponentsInChildren(Camera)` 找名字叫 `Camera` 的主相機，把 `orthoHeight` 抄過去（不抄就會縮放不對）
- sprite 的 `UITransform` 尺寸設成可見區大小，sprite 跟 camera 的 y 都設成 `-gameView.node.position.y`（抵銷 GameView 的位移）
- `camera.targetTexture = renderTex` → `spriteFrame.texture = renderTex`
- 尾端**釋放上一次的 SpriteFrame 與 RenderTexture**（`:158-164`），防 resize 反覆觸發時洩漏
