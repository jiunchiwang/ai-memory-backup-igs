## 二、專案層 `.codex/hooks.json` 有**兩道靜默信任閘門**

| 閘門 | 條件 | 實測 |
|---|---|---|
| (a) **專案信任** | `~/.codex/config.toml` 要有 `[projects.'<絕對路徑>'] trust_level = "trusted"` | `git init` 過、用 `-C` 或真的 `cd` 進去，全都無效；補上 trust 後**立刻生效** |
| (b) **hook hash 信任** | 腳本本身要經互動式 `/hooks` review | 專案已 trusted 但不加 `--dangerously-bypass-hook-trust` → 仍 0 捕獲 |

```bash
codex exec --dangerously-bypass-hook-trust \

```

- shell 的 tool 名是 **`Bash`**，不是 `shell`
- 執行時 CLI 會印 `hook: PreToolUse` / `hook: PreToolUse Completed`，這是唯一的正向訊號——**沒印就是沒跑**
